# Revise_Miyou

MiYou 关键词自动回复时间限制的**实验性独立补丁**，不是原插件源码还原，也不是修改完成并验证的 MiYou.dylib。

## 环境与构建
目标：微信 8.0.80 / iOS 16.4.1 / trollfool。GitHub Actions 在 macOS 使用 Xcode iPhoneOS SDK 构建 ARM64 dylib 并执行时间算法测试。Actions 页面下载 artifact；构建通过只代表编译和单元测试通过，不代表微信实测通过。

## 使用
保留原 MiYou.dylib；另将 ReviseMiyouSchedule.dylib 通过支持多库注入的工具加载到同一个微信进程。不能用本补丁替换原插件。具体 trollfool 是否支持该方式尚未验证。补丁最多等待原插件类加载 120 秒。
进入 MiYou 的关键词自动回复属性分组，直接操作“启用在线时间限制”左右开关；点击“在线时间段（期间不回复）”填写 HH:mm 并保存。无需长按。保存时间不会自动改变开关状态。默认关闭限制，默认区间 08:00–23:00。区间内暂停关键词回复，区间外仍遵守原关键词开关和匹配规则。左闭右开，支持跨午夜，相同起止不暂停。使用手机本地时区。

## 当前限制（必须阅读）
- 根据已定位的 MYReplyConfig.mIsKeywordReplyMessage 返回类型 B，进行 Objective-C runtime 拦截。保留原实现并先读取原值，不写原开关。
- 构建关键词分组及本补丁触发设置刷新时，getter 保留原开关值，避免原关键词开关随时间变化。其他未识别 UI 调用路径仍可能受影响。
- 尚未完整追踪最终发送路径，已排队的延迟消息可能跨入禁回区间后仍发送。本版本不是最终发送层解决方案。
- v2 沿用原设置页的 addSwitchCellForSel:title:on: 和 addNormalCellForSel:title:rightValue:，在 addKeywordMessageSection 构建期间向原分组追加两行。没有长按入口；界面仍待实机验证。
- 更新微信/插件后只有相关类、方法和语义仍兼容才可能有效，不能保证持续兼容。
- 独立补丁随原插件的加载顺序、其他 Hook 和注入工具行为而变化。发生异常应先移除补丁恢复。
- 无原始 dylib、IPA、账号、凭据或签名证书上传。Actions 仅构建新源码，ad-hoc 签名不等于 App 安装签名。
