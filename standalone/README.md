# 独立关键词自动回复（实验版）

全新实现，不是原始 MiYou 源码还原，不调用 MYReplyConfig 或 MiYou 设置/授权接口。
本目录源码以 MIT 许可提供；不包括原库、微信私有实现或第三方代码。旧版配套补丁仍在 src/，不是本项目的独立版产物。

## 功能
- 私聊新文本；精确/包含匹配，区分大小写，按列表顺序仅回复首条匹配规则。
- 本地规则新增、修改、删除，最多100条；关键词1-512字，回复1-2048字（按NSString长度计）。
- 默认关闭总开关及时间限制。默认在线区间08:00-23:00，区间内不回复，区间外按关键词规则回复。
- 手机本地时间；包含开始、不包含结束；支持跨午夜，相同起止不暂停。
- 每个账号/联系人60秒冷却；内存去重最多2048条。新消息时间必须在本次插件加载后、最近120秒内。重启会清除内存状态。
- 不设延迟队列；发送前再次核对开关、当前时间、账号和旧插件冲突。
- 设置页底部显示版本、UTC构建时间和完整提交号。

## 安装（尚未实机验证）
1. 先备份，建议仅用测试账号。完全移除 MiYou.dylib 及旧 ReviseMiyouSchedule.dylib，避免重复回复。检测到 MYReplyConfig 时独立版停止回复。
2. 只注入 ReviseKeywordStandalone.dylib，完全退出微信后重新打开。
3. 微信「我 → 设置」右上角查看「关键词回复」，不需要长按，不需要打开原插件页面。
4. 添加规则，打开总开关；如需要，单独打开在线时间限制。
5. 用另一测试账号私聊触发，并检查在线边界、冷却、自发消息不触发和无匹配不回复。

入口使用 NewSettingViewController / MMNewSettingViewController 候选类名，尚未对提供的微信可执行文件核实；如果右上角没有入口，表示设置类适配尚未成功，不代表已经可用。

## 微信适配与已知限制
- AsyncOnAddMsg:MsgWrap:、AddMsg:MsgWrap: 和消息字段名在原 dylib 中出现，属于静态线索，不是收发成功证明。
- CMessageMgr、CMessageWrap、MMServiceCenter.defaultCenter/getService: 为候选私有接口，运行时严格检查参数和返回签名；缺失/不一致则跳过，不猜内存偏移。
- 不匹配群聊、公众号及常见系统账号；未实现完整联系人分类，其他特殊微信账号不能保证全部排除。
- 不保证所有离线同步均能识别；时间门限会主动漏掉较旧消息。
- Hook 安装成功不等于发送适配成功，调用发送接口也不等于消息送达。
- 仅支持文本；不处理群聊、图片、语音、正则表达式、群发、定时发送。
- 无后台保活。iOS挂起、锁屏受限或微信被杀后不保证处理；手机时间变更会影响判断。
- 尚无iOS实机验证。目标iOS16+ ARM64；微信升级可能失效。
- 本源码不引入HTTP请求、遥测、远程配置、剪贴板或关注验证；消息发送仍通过微信自身网络服务。配置及回复文本明文保存在微信沙盒NSUserDefaults，不记录聊天日志。
- Actions验证Foundation层匹配/时间算法、编译及动态依赖，不证明设备运行安全、稳定或后台在线。ad-hoc签名不等于安装签名。

## 源码与构建
Engine.m 为实际运行的时间/匹配函数；Tests.m 直接链接该文件，覆盖时间区间、总开关与限制开关组合、非法输入及匹配顺序。
Plugin.m 包含配置、独立UIKit设置页、适配层、去重/冷却与发送前过滤。
构建流程：.github/workflows/standalone.yml；Actions名称 Build standalone keyword reply。
可在macOS使用Xcode iPhoneOS SDK按workflow命令构建；无Theos/Substrate依赖。
